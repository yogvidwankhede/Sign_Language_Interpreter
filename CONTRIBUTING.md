# Contributing

This repository is a research prototype derived from
[gabguerin/Sign-Language-Recognition--MediaPipe-DTW](https://github.com/gabguerin/Sign-Language-Recognition--MediaPipe-DTW)
(see the Attribution section of the README). Issues and pull requests are welcome.

## Before you start

- Open an issue first for anything larger than a typo or small fix.
- Keep pull requests to one change. Explain what you changed and how you checked it.
- There is no test suite yet. If you fix behaviour, please add a test that fails before the fix.
- Do not add sign videos or landmark files to the repository unless you can show you have the right to share them and
  the signers' consent. The project does not redistribute data.
- If you used an AI assistant to write part of the change, say so in the pull request description.

## Scope

The project recognises isolated signs by template matching on hand landmarks. It does not translate or interpret a sign
language, and contributions should not describe it as doing so.
