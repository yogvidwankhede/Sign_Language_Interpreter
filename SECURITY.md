# Security policy

This is a research prototype with no supported releases. Please report a vulnerability privately through GitHub's
"Report a vulnerability" button on the Security tab of this repository, rather than in a public issue.

Known issues, not vulnerabilities in the project's own code: the pinned dependencies are old (`mediapipe==0.8.7.3`,
`pytube==11.0.1`, `opencv` 4.5.x), and `pytube` is no longer maintained.
